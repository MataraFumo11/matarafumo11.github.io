# 东方简历 · 地灵殿

一个纯静态、零依赖的个人简历网站。所有内容都可以**在网页里直接改**，不需要写代码。

文件说明：

| 文件 | 作用 |
| --- | --- |
| `index.html` | 网页入口，双击它打开 |
| `styles.css` | 页面样式（配色、排版） |
| `app.js` | 编辑、保存、分享、二维码功能 |
| `qrcodegen.min.js` | 二维码生成组件（本地内置，不联网） |
| `README.md` | 本说明 |

> ⚠️ 首次发布前请把示例的邮箱 `yourname@school.edu.cn`、GitHub 链接等改成你自己的脱敏信息；**不要在公开仓库里放真实手机号、家庭住址**。

---

## 一、怎么打开和编辑

1. 双击 `index.html`，用 Chrome 或 Edge 打开。
2. 打开编辑面板，任选一种方式：
   - **长按**页面顶部的「东方简历」标志约 1 秒（手机也可以）；
   - 在地址栏网址末尾加上 `#edit=1` 后回车；
   - 电脑上按 `Ctrl + Shift + E`。
3. 左侧标签页分别对应：基本、联系、技能、兴趣、作品、高级。

### 编辑要点

- **改文字**：直接在输入框里改，改完点右下角「保存更改」。
- **隐藏某项**：在对应标签页里，点条目左侧的眼睛图标，变灰即隐藏；再点一次恢复。
- **隐藏整个模块**：每个标签页最上方的开关「显示xxx模块」。
- **加条目**：点「添加xxx」，展开后填内容。
- **删条目**：点条目右侧的垃圾桶图标。
- **排序**：点条目的上/下箭头。
- **换头像（方法一，最简单）**：打开编辑面板 →「基本」→ 点圆形头像预览或直接点「选择文件」，选中本地 PNG/JPG 图片（≤5MB）。程序会把图片居中裁成正方形、压缩到 192px，外层圆形头像框会自动适配，不会变形。透明 PNG 会自动垫一层深玫瑰底色，不会变成黑块。点右下角「保存更改」后生效。
  - 也可以直接把 PNG 文件**拖到**那个圆形头像预览框里。
- **换头像（方法二，适合发布后作为默认头像）**：把图片文件复制到 `G:\operation` 文件夹，和 `index.html` 放在一起；然后用记事本打开 `app.js`，找到 `profile` 里的 `avatar`，改成对应的文件名（例如当前默认是 `avatar: 'avatar.jpg'`）。上传仓库时要把这张图片一起上传。这样分享链接里只包含文件名，二维码不会很长。
  - 当前项目里已经放好一张 `avatar.jpg` 作为示例默认头像；你以后换成自己的图片时，直接用同名文件覆盖它，或在 `app.js` 里改文件名即可。
- **保存位置**：点保存后数据存在**你这台电脑的浏览器**里，刷新不会丢。换电脑/换浏览器不会自动同步，请用下面的「分享链接」。

高级标签页还提供 JSON 导出/导入（备份）和恢复默认内容。

## 二、生成分享链接和二维码

1. 编辑面板 → 「高级」标签页。
2. 在**站点基础地址**里填正式网址（发布后填写，例：`https://你的用户名.github.io/index.html`）。留空则使用当前网址。
3. 点「生成分享链接」，文本框里出现一长串地址。
4. 点「复制链接」发给别人；或点「生成二维码」→「下载 PNG」得到二维码图片。
5. 如果提示链接太长，精简一下文字、换小头像，或先把网站发布上线再生成。

**关于访客看到的版本**：链接里的 `#d=...` 是一份「快照」。你改完内容后，必须**重新生成链接和二维码**并重新发送，别人看到的才是新内容。别人打开快照时不会改动你电脑里的数据。

> **本地文件的重要限制**：还没发布时，二维码指向的是你电脑上的 `file:///C:/.../index.html`，**只有这台电脑能打开**。别人手机扫码会失败。要让实验室扫码访问，必须先按下面步骤发布到 GitHub Pages。

## 三、发布到 GitHub Pages（浏览器操作，不用敲命令）

前提：你已有 GitHub 账号并已登录。

### 第 1 步：新建仓库

1. 打开 <https://github.com>，点右上角 `+` → **New repository**。
2. **Repository name** 填：`你的用户名.github.io`
   - 例如用户名是 `lige2026`，就填 `lige2026.github.io`，必须完全一致。
   - 这个仓库名决定了你的网址：`https://lige2026.github.io/`。
3. Description（可选）：填「个人简历」。
4. 勾选 **Public**（免费 GitHub Pages 必须是公开仓库）。
5. **不要勾选** `Add a README file`、`Add .gitignore`、`Choose a license`，保持空仓库。
6. 点 **Create repository**。

### 第 2 步：上传文件

1. 在新仓库页面找到 **uploading an existing file** 链接并点击（或直接把文件拖到页面上的拖拽区域）。
2. 一次性选中这 5 个文件：`index.html`、`styles.css`、`app.js`、`qrcodegen.min.js`、`README.md`。
3. 等待上传完成，点 **Commit changes**。
4. 确认仓库首页能看到这 5 个文件，且 `index.html` 在**根目录**（不要在文件夹里）。

### 第 3 步：开启 Pages

1. 在仓库页面点 **Settings**（顶部标签栏）。
2. 左侧找到 **Pages** 并点击。
3. **Build and deployment** → Source 选 **Deploy from a branch**。
4. Branch 选 `main`（如果下拉里只有 `master` 就选 `master`），文件夹选 **`/ (root)`**。
5. 点 **Save**。
6. 等 1–3 分钟刷新页面，顶部出现绿色提示：`Your site is live at https://你的用户名.github.io/`。
7. 用**无痕窗口**打开这个网址，确认页面正常、中文不乱码。

### 第 4 步：生成能跨设备扫描的二维码

1. 打开线上网址 `https://你的用户名.github.io/`。
2. 打开编辑面板（长按 Logo / `#edit=1` / `Ctrl+Shift+E`）→ 高级。
3. 「站点基础地址」填 `https://你的用户名.github.io/index.html`，点「生成分享链接」→「生成二维码」→「下载 PNG」。
4. 用**手机流量**（关掉 WiFi）扫码测试，应能打开你的简历页。
5. 把链接或二维码发给实验室即可。

## 四、以后改了内容怎么更新

- 只改简历内容：本地打开 `index.html` → 编辑面板改 → 保存 → 重新生成分享链接/二维码 → 重新发送给对方。
- 想让线上默认页面也变：把改好的文件重新上传到同一个 GitHub 仓库，覆盖同名文件并 Commit，等 1–3 分钟生效。
- 如果二维码里带 `#d=` 快照，内容一变就必须重做二维码；如果二维码只指向 `https://你的用户名.github.io/`，则不用重做。

## 五、常见问题

| 现象 | 解决办法 |
| --- | --- |
| 打开是 404 | 仓库名必须是 `用户名.github.io`；`index.html` 必须在根目录；确认 Pages 已开启并等几分钟 |
| 没有样式/按钮失效 | 检查 5 个文件名是否完全一致、都在根目录（服务器区分大小写） |
| 中文乱码 | 文件必须保存为 UTF-8；本项目的 `index.html` 已声明 `<meta charset="UTF-8">` |
| Browser 里改了但线上没变 | 线上和本地是两份数据；需要重新上传文件并 Commit，或用分享链接发送快照 |
| 页面没更新 | 用无痕窗口或按 `Ctrl + F5` 强制刷新，排除缓存 |
| 二维码扫不出 | 链接太长；精简文字、压缩头像，或让二维码只指向简洁的正式网址 |
| 微信里打不开链接 | 点右上角「…」→「在浏览器打开」 |
| 编辑面板打不开 | 在网址后加 `#edit=1` 回车，或按 `Ctrl+Shift+E` |
| 提示存储不可用 | 某些浏览器限制本地文件的存储；用分享链接发送即可，对方仍能看到内容 |

## 六、隐私提醒

GitHub Pages 免费版要求仓库公开，所以**任何拿到链接的人都能看到网站内容**。请只放你愿意公开的信息（例如学校邮箱），不要放手机号、身份证号、家庭住址等敏感信息。本示例中的联系方式均为占位符。
